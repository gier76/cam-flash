ESP32-CAM_MJPEG2SD v9.7 — MQTT + FTP Build

Custom Firmware für dein AI-Thinker-Clone-Modul: MQTT und FTP aktiv, SMTP / Telegram / HTTPS(Certs) / WebDAV / Telemetry / Mic / UART deaktiviert. Partition: min_spiffs (2 App-Slots) → danach OTA über die Cam-Webseite möglich.

Vorbereitung
  • USB-FTDI-Shield an der Cam, GPIO0 auf GND ( flashing-Modus)
  • Cam per USB an diesen Rechner (Chrome oder Edge, kein Firefox)
  • Button unten klicken → Serial-Port erlauben → Flash startet
  • Nach Flash: WiFi in der Cam-UI setzen, MQTT-Broker 192.168.1.21:1883 mit Login espcam
